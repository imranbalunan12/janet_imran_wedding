# Photo folders

Put the couple’s photos here. Keep the file names below so they appear automatically. JPG, PNG, or WEBP all work if you match the name and change the extension in `lib/photos.ts`.

```
public/photos/
  landing/                 # fade slideshow on the Open Invitation screen
    01.jpg
    02.jpg
    03.jpg
    04.jpg
  home/
    hero/
      portrait.jpg         # oval portrait on the home section
    countdown/             # optional extras around the timer
  couple/
    groom/portrait.jpg
    bride/portrait.jpg
  gallery/                 # Captured Moments grid
    01.jpg … 09.jpg
  events/
    ceremony/cover.jpg
    reception/cover.jpg
  entourage/
    parents/
    principal-sponsors/
    best-man/
    maid-of-honor/
    candle/
    veil/
    cord/
    groomsmen/
    bridesmaids/
    little-entourage/
  attire/
  prenup/
    cover.jpg              # shown until the YouTube video id is set
  rsvp/
  admin/
```

Until a file exists, the site uses a soft placeholder so layout still looks complete.
